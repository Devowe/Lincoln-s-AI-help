# Two Cats Color Relief

Image-guided sculpted relief, 230 × 165.6 × 9.26 mm.

Download [Two_Cats_Color_Print_Pack.zip](Two_Cats_Color_Print_Pack.zip), extract it, and open the chosen 3MF in Bambu Studio. The pack includes four-color and six-color models, a color preview, print instructions, mesh checks, and source scripts.

- Four colors: bronze/tan, gray, black, white.
- Six colors: adds gold eyes and a pink nose.
- Starting settings: PLA, 0.2 mm nozzle, 0.10 mm layers, 3 walls, 15% gyroid, supports off, flat back down.

Keep all parts assembled and check filament assignments before slicing. The model uses simplified colors and approximate sculpting from the supplied artwork. Geometry checks passed; Bambu Studio import and physical printing remain untested.
